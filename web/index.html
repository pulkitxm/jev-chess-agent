Connect your browser

  1. Run npm run build, then open chrome://extensions in Chrome.
  2. Enable Developer mode, choose Load unpacked, and select this project's dist/extension folder.
  3. Copy this local pairing code into the extension. Your TypeSafe key is stored only in the local service and sent only to TypeSafe.

Start a game

Open Maximum (3200), select your color, and start a fresh standard game. Open the extension and choose Play automatically or Play one move.

Jev is the sole move selector. The rules library enforces legal moves, not playing strength. A win against Maximum has not been established.
